# クラン ホームページ初稿

## ファイル構成
- `index.html` : ページ本体
- `style.css` : デザイン・レスポンシブ対応
- `script.js` : スマホメニュー、メールリンク設定
- `assets/` : 画像素材（外観写真1点＋仮画像SVG）

## 表示確認
`index.html` をブラウザで開くと確認できます。

## 公開前に必ず行うこと
1. `assets/` 内の `*-placeholder.svg` を実際の写真に差し替える  
   - `hero-placeholder.svg` : 仮のメインビジュアル（イラスト）
   - `craft-placeholder.svg` : ものづくり
   - `lightwork-placeholder.svg` : 内職・軽作業
   - `facility-placeholder.svg` : 施設内
   - `activity-placeholder.svg` : 活動風景
   - `exterior.jpg` : 今回提供いただいた建物外観写真（掲載済み）
   - 差し替える場合はHTML内の画像ファイル名も合わせて変更してください。
2. お問い合わせメールアドレスは `todayfull@kocoiro.com` に設定済みです
3. 工賃・利用条件・在宅利用・送迎エリアなどの掲載内容を事業所側で最終確認する
4. 既存サイトのサーバーに公開用ディレクトリを作り、ファイル一式をアップロードする
