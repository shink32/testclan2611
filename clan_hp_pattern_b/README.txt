Clan ホームページ Bパターン
==========================
1. index.html をブラウザで開くと確認できます。
2. サーバーに公開する場合は、このフォルダ内のファイル一式を公開ディレクトリへアップロードしてください。
3. 画像は仮画像です。assets/hero-placeholder.svg と assets/work-placeholder.svg を実際の写真に差し替えてください（ファイル名を維持するとHTML修正は不要です）。
4. メールアドレス・電話番号・住所・運営会社情報は現時点でいただいている内容を反映しています。
5. 公開前に、工賃例・送迎範囲・サービス内容等の最新情報をご確認ください。
